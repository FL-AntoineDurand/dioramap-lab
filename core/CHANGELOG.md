## 0.2.2 — 2026-05-06 (HTTP /healthz + /ws fast-fail; PLAN-PROTOCOL P8 partial)

- **`GET /healthz` returns 200 OK + body `"ok\n"`** in <1 ms.  Probe-able
  by any plain-HTTP uptime monitor (UptimeRobot, BetterStack, etc.) —
  closes the gap that caused the 2026-05-06 false-positive: WS-only
  endpoint was unmonitorable from the outside, leading the operator to
  add UptimeRobot probes against `/ws` which 502'd in both healthy AND
  dead states (libwebsockets holds plain-HTTP GETs to `/ws` open until
  nginx's 15s `proxy_connect_timeout` fires).
- **`GET /ws` (plain HTTP, no WS upgrade headers) now returns 426
  Upgrade Required** in <1 ms with body `"use WebSocket\n"`, instead of
  hanging 15s.  Side benefit: nginx no longer 502s for these probes;
  it serves 426 cleanly from upstream.
- **Other paths return 404 Not Found** with body `"not found\n"`.  No
  static file serving from the processor (nginx in front handles that
  in prod per `PLAN-DIORAMAP-DEPLOY.md`).
- Implementation: ~40 lines added to `core/src/server/server.c`
  `protocol_cb` — new `case LWS_CALLBACK_HTTP` handling.  No
  `session_t` allocation on the HTTP path (HTTP requests don't carry
  session state).  Closes part of `PLAN-PROTOCOL.md` P8 (just
  `/healthz`; `/api/catalog` + `/api/schema/*` stay deferred — no
  consumer; static stays nginx's job).
- All 10 integration scenarios still pass; WS path unchanged.

## 0.2.1 — 2026-05-05 (encapsulation refactor + ground step ASPRS class-2 + validation matrix infra)

- **Server encapsulation refactor** (`d91f0ab`). `session_t`,
  `session_mgr_t`, `batch_ctx_t` became opaque types defined in
  dedicated `.c` files; all field access goes through accessor /
  mutator functions that take the internal mutex. The compiler
  now enforces what was previously convention-only. Closes the
  structural drift surface that caused
  `v3/docs/BUG-cache-hit-runner-cleanup.md` (the journal-acc race).
  `core/src/server/server.c` is now pure lws-glue (~1100 lines, was
  ~2270); new files `session.c`, `session_mgr.c`, `batch_ctx.c`,
  `server_internal.h`. clang `-Wthread-safety` annotations
  (`v3/thread_safety.h`) auto-enabled on any clang build — catches
  forgot-to-unlock / double-acquire / lock-order at compile time.
  Heap-correctness fixes from the same audit: `parse_produced_json`
  realloc UAF on partial OOM, `cp_verify_key` cache-slot reuse
  after re-acquire, `store_put` ownership-contract dead code.
  See updated `v3/docs/CONCURRENCY.md` (invariants 8–10,
  anti-patterns 11–14, §12.3 lock-order, §12.6 mark DONE).
- **Ground step v2** (`72abaf4`): `lidar-ground` now filters to
  ASPRS class 2 only (was: classes 2 + 9). Parcel-fence height
  bumped 1.0 m → 1.5 m for better cadastre alignment. Affects
  ground-derived artifacts on viewer pipelines; outputs differ
  bit-for-bit from 0.2.0 → cached entries from old runs are no
  longer hit (deterministic + content-addressed → new identity →
  new content; old artifacts age out via LRU naturally).
- **Validation matrix infrastructure** (`5bee4cb`). Internal — no
  runtime impact on the prod binary. Adds `tests/integration/`
  (10 scenarios covering every WS handler the server ships:
  RUN/SUBSCRIBE/CANCEL/INVALIDATE/LIST_RUNS/REHYDRATE_RUN/RECONNECT
  + the abrupt-disconnect grace path), `tests/fuzz/` (libFuzzer
  targets gated on `DIORAMAP_FUZZ=ON`), CMake options
  `DIORAMAP_TSAN/COVERAGE/FUZZ`, plus `v3/docs/plan/PLAN-VALIDATION-
  MATRIX.md` + `v3/docs/quality/README.md`. All 10
  scenarios pass under TSan on prod (TSan won't run on the WSL2
  dev box; bundle/scp/run procedure documented). The encapsulation
  refactor + audit fixes are operationally validated end-to-end
  via this matrix.
- Research-track step libs (PolyFit roof-recon Phase 2.0–2.4,
  commits `5ee18d5`..`2025c12`) are gated on `DIORAMAP_RESEARCH=ON`
  and **do not enter the prod binary** — out of scope here. See
  `v3/docs/plan/PLAN-THIRD-PARTY-RESEARCH.md`.

## 0.2.0 — 2026-05-01 (D6 obfuscation + cache integrity + canonical-location fix)

- **D6 obfuscation Phase 2 — full ship.** Step / artifact / pipeline
  names land as `tt_<8hex>` tokens in the binary's rodata. Pipelines
  are baked into the binary (`embedded_pipelines.c` generated by
  `scripts/obfuscate.mjs embed`); the Dockerfile no longer ships
  `/opt/dioramap/pipelines/`. Source uses friendly names wrapped in
  `t("…")`; CMake `obfuscated_sources()` runs sources through the
  rewriter when `DIORAMAP_OBFUSCATE=ON` (now the prod default in the
  Dockerfile). Configure-time staleness guard refuses to build if
  any `t("…")` call site references a friendly missing from the
  committed `obfuscation-map.json`. Audit: 0 production-identifier
  leaks in the binary; 3 acceptable false positives confined to a
  non-production demo step's JSON output keys. Commits `0c8e285`,
  `8904693`, `c77741a`, `7afc6b1`. Operator log decoder:
  `… 2>&1 | node v3/scripts/obfuscate.mjs decode`.
- **D6.5 fix**: `canonical-location` artifact reclassified to PUBLIC
  visibility + `lidar-ground-grid` dropped from public-tier subscription
  set. Fixes the unblock-public-tier-viewer regression. Commit
  `20a40e0`.
- **store: write-through put** — every value lands on disk synchronously
  rather than waiting for the janitor to flush. Closes a window where
  a crash between put + janitor would leave the intent map referencing
  a value not yet on disk. Commit `886f1da`.
- **store: startup integrity audit** — at open time, scan the disk
  tier and log an event when intent.log entries reference values
  missing on disk (or vice versa). Operator-visible signal for cache
  desync after manual intervention or partial writes. Commit `cae6172`.
- **runner: F2/F3 self-heal on cache desync** — when a step's claimed
  cache hit fails to load, runner falls back to recompute + emits a
  structured event. Commit `19b4c87`.
- **boundary-regularize**: toggleable scorer terms + real two-sided
  WSD. Algorithmic improvement to the boundary chain; not visible to
  the SDK protocol. Commit `5d29a25`.

**Operator note for this release**: deletes the previous v0.0.0 + v0.1.0
docker images from the prod box after the new container is healthy —
both pre-date D6 obfuscation and have plain pipelines + step names in
their rodata. See deploy execution log + the followup prune step.

## 0.1.0 — 2026-04-30 (D0 + D5a-server-side + D6.5 ship)

- **D0**: pipeline JSON gains `attributions[]` array (label + url).
  `pipeline_attributions(p, n_out)` accessor. `CATALOG_RESPONSE` payload
  carries `attributions` field verbatim. Backwards-compatible — older
  clients ignore the new field. Commit `5352cd1`.
- **D6.5**: artifact-tier visibility enforcement. Three gates:
  CATALOG_RESPONSE filters debug-only writes by tier;
  `handle_subscribe_message` rejects forbidden artifacts with
  `FORBIDDEN_ARTIFACT`; RUN handler validates `subscribe[]` before
  spawning runner. Tier→visibility allow-list as a small const table.
  Commit `9d1662a`.
- **D6.5 fix**: closed-by-default auth — reject keyless WS connections
  when CP is enabled. Previously a keyless connection landed at DEBUG
  tier (full algorithm graph in CATALOG_RESPONSE). Now: keyless +
  CP-enabled → `AUTH_REQUIRED` + clean close. New `--dev-key` /
  `DIORAMAP_DEV_KEY` escape hatch for staging / lab-ui-against-CP-stub
  flows (≥16-char shape check, loud WARN at startup so misconfigured
  prod is grep-able). CP-disabled path unchanged (still DEBUG tier
  for offline dev). Commit `af38cae`.

## 0.0.0 — 2026-04-29 (Phase A foundations + first prod deploy)

Initial seed entry. The processor binary at this version is the
result of all Phase A milestones (A1–A16) plus Phase B (B1–B10)
documented in `v3/docs/plan/MAIN-IMPL-PLAN.md`. Notable subsystems
shipped at this point:

- A1–A6 runtime: thread pool, content-addressed store with hot+warm
  tiers (per `HASH-MODEL.md`), DAG runner with cache skip, structured
  logging.
- A7+A8 protocol/transport: WS via libwebsockets (TLS terminated by
  nginx), batch mode CLI, full SESSION_STARTED / CATALOG / RUN /
  SUBSCRIBE / CANCEL / RECONNECT lifecycle.
- A9 fetchers: libcurl + mbedTLS, IGN wrappers (`fetch-ortho-rgb`,
  `fetch-ortho-irc`, `fetch-elevation`, `fetch-cadastre-parcels`,
  `fetch-cadastre-buildings`).
- A10 control-plane client: cached `verify-key` + ring-buffered
  `record-usage` with dedicated flush thread.
- A14 telemetry: extended `usage_events` with run-level fields.
- B1–B10 viewer pipeline: end-to-end `viewer-full` against IGN
  produces the full artifact catalog.

This is the first version cut for prod deployment to dioramap.com.
Any further work — D0 attributions, D6.5 visibility gating, D6
pipeline embedding — bumps from here.
