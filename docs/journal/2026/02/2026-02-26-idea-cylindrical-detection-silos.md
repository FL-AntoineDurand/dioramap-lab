# Idea: Cylindrical Detection for Silos

## What
Add cylindrical surface detection for silo buildings, which cannot be accurately represented as planar segments.

## Where Mentioned
NEXT-STEPS Idea 4, ALGORITHM-GENEALOGY §4.3.

## Why Not Yet Implemented
Requires new geometry primitives beyond the current plane-only representation.

## Note
Silos already scored +12.4 with V3 histogram path. The current plane approximation works acceptably but could be improved.

## Expected Impact
Medium. Better representation of curved surfaces for solar yield calculations.
